# Segurança

## Reportar vulnerabilidades

Se encontrar um problema de segurança neste repositório, **não abra issue pública** com detalhes exploráveis.

Envie um contato privado via [LinkedIn](https://www.linkedin.com/in/yuri-medeiros-1071533b4/) ou abra issue genérica pedindo contato seguro.

## Boas práticas do projeto

- Não commitar `.env`, chaves ou backups com dados reais
- Usar `.env.example` / `.env.production.example` como referência
- Credenciais de seed/local **nunca** devem ir para produção
- Em ambientes reais, trocar senhas padrão e restringir CORS/origens

Obrigado por ajudar a manter o SIGAPS mais seguro.
